완료·푸시한 개인 시간표는 `20e2cf5`, KST 접속 로그·관리자 화면은 `d64ca1b`다. 마지막 배치에는 임베드·생성기, timed 캘린더 TS/Python 클라이언트 호환, 선택적 NEIS 열량·영양·원산지 API 필드가 포함된다. 영양 화면·오늘 통합 메뉴는 미완료다.

마지막 검사: 백엔드 132개, 프런트 단위 97개, TS 클라이언트 6개·Python 7개 통과. Svelte 오류·경고 0. 임베드 Chromium/WebKit 10개 통과, 배포 빌드 성공. 관리자 브라우저 4개·개인 시간표 포함 기존 회귀 19개 통과 및 WebKit 오프라인 1개 skip은 앞선 배치 기록이다.

보안 검토: 임베드 문자열 textContent·속성 인용, fragment 길이·중복·범위, 실제 학년·반만 선택, 빈 자료의 임의 학급 생성 차단, 늦은 응답 무시를 확인했다. NEIS는 선택 필드 4,000자·응답 16MiB·페이지 총량을 제한하며 키를 노출하지 않는다. 영양 값은 추정하지 않는다.

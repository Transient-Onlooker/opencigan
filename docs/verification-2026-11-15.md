## P0: 시간표 대상 일치, 공백 표시 및 운영 구독 확인

- 화면에 표시된 학교·주차와 응답의 식별자가 일치할 때만 시간표로 사용한다. 공유 링크를 검증 중이거나 선택한 학급의 기록을 확인하지 못하면 학급 링크와 구독을 열 수 없다. 주차를 옮기면 열린 링크를 닫는다. 교사 시간표 내보내기는 해당 교사의 수업 기록을 기준으로 한다.
- 주간 시간표에서 수업 기록이 전혀 없는 평일을 표시한다. 저장된 데이터에서 발견된 공백은 그렇게 표시하며, 공백을 휴업일로 판단하지 않는다. 과거 제보의 원본 응답은 확보되지 않았다.
- 모바일 하단 메뉴는 가로·하단 안전 영역을 반영한다. 좁은 세로 및 가로 뷰포트에서 입력 포커스 중 숨겨지고, 포커스 해제 후 마지막 수업과 검색 결과를 메뉴 위로 스크롤할 수 있음을 확인했다. 실제 iOS·Android 키보드와 회전은 별도 확인 대상이다.
- 모의 WSGI 프록시에서 같은 클라이언트의 61번째 요청은 429, 별도 클라이언트는 404(테스트 경로의 정상 응답)를 받았다. 요청 제한과 접속 로그가 같은 IP를 사용했으며, 전달 체인의 앞에 추가된 주소는 제한 기준을 바꾸지 않았다. 운영 환경에서 외부 네트워크 두 곳의 실제 IP 식별은 확인하지 않았다.
- 공개 HTTPS 점검: `opencigan.mcv.kr/api/v1/timetable.ics`는 GitHub Pages에서 HTML 404를 반환했다. 이후 RPi API를 `7bd443e` 백엔드로 배포한 뒤 기존 Funnel에서 실제 `text/calendar`, ETag 및 조건부 요청 304를 확인했다. 구독 URL, 터널, DNS는 변경하지 않았다.
- 로컬: Python 132개, 프런트 단위 101개, Svelte 진단 오류·경고 0. 배포용 빌드 성공. Chromium·WebKit 회귀 39개 통과(학교 전환 중 늦은 응답 포함), 기존 Windows WebKit 오프라인 1개 skip. 기존 미커밋 급식 기능도 같은 작업 트리에서 검사했지만 이 배치와 별개다.

## 날짜·공유·학급 선택 신뢰성

- 급식 날짜는 편집값과 적용값을 구분하고 실제 달력 날짜만 적용한다. 입력과 화살표 이동은 1900-01-01~9999-12-31 범위를 유지한다.
- 공유 학교는 최신 검색 결과의 ID·이름·지역이 일치해야 하며, 학급은 최신 시간표에서 존재가 확인된 뒤 저장한다.
- 수동 학교·학년·반·즐겨찾기 전환은 공유 복원을 취소한다. 없는 반, 네트워크 실패, 오래된 자료, 빈 자료는 이전 선택으로 복구한다. 이전 선택이 없으면 선택기를 열어 오류와 해결 경로를 표시한다.
- 복구 후 취소된 요청의 후처리가 현재 상태와 마지막 정상 오프라인 자료를 덮지 않도록 한다. 검증 대기 중 즐겨찾기·링크·내보내기를 제한한다.
- 반 입력은 편집을 마칠 때 적용하며, 무효 입력은 현재 선택값으로 돌아간다. 빈 시간표의 사유는 원본 근거 없이 단정하지 않는다.

## 실제 교시 시각 캘린더

- `mode=timed&times=1:0900-0950,...`를 추가했다. KST 입력을 UTC 순간으로 직렬화하며, 시각 없는 교시는 명시적 종일 일정으로 유지한다. 기존 모드와 단일 수업 UID를 보존하고 복수 수업 UID 충돌을 해결했다.

## 개인 시간표·일정

- 학교·학급별로 공식 원본과 분리한 개인 시간표를 브라우저에 저장한다. 같은 요일·교시에 다시 저장하면 수정하며, 특정 날짜 수업은 해당 주의 정기 수업보다 우선한다. 삭제·PNG 저장, 개인 일정·시험 목록과 주간 표시를 지원한다.
- 저장 자료는 최대 수업 200개·일정 200개·256KiB로 제한하고 날짜·교시·문자열을 검증한다. HTML로 삽입하지 않으며 서버·공유 URL로 보내지 않는다. 저장 거부 시 오류를 표시한다.
- 개인 시간표 및 기존 선택 회귀 Chromium/WebKit 19개 통과·기존 WebKit 오프라인 1개 skip. PNG 다운로드, 추가·수정·삭제와 재시작, 공식 시간표 유지가 포함된다. 단위 검사 97개 통과, Svelte 오류 0·경고 0, 배포 빌드 성공. 97개에는 다음 배치의 임베드 단위 8개가 포함되며 임베드 완료 판정을 뜻하지 않는다.
- 모바일 입력 포커스 중 고정 메뉴를 숨기되 배치를 유지하여 blur 때 저장 버튼 위치가 바뀌는 문제를 수정했다. 실제 모바일 키보드·회전은 별도 확인 대상이다.

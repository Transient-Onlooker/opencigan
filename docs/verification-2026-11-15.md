# 2026-11-15 구현·검증 기록

## 날짜·공유·학급 선택 신뢰성

- 급식 날짜는 편집값과 적용값을 구분하고 실제 달력 날짜만 적용한다. 입력과 화살표 이동은 1900-01-01~9999-12-31 범위를 유지한다.
- 공유 학교는 최신 검색 결과의 ID·이름·지역이 일치해야 하며, 학급은 최신 시간표에서 존재가 확인된 뒤 저장한다.
- 수동 학교·학년·반·즐겨찾기 전환은 공유 복원을 취소한다. 없는 반, 네트워크 실패, 오래된 자료, 빈 자료는 이전 선택으로 복구한다. 이전 선택이 없으면 선택기를 열어 오류와 해결 경로를 표시한다.
- 복구 후 취소된 요청의 후처리가 현재 상태와 마지막 정상 오프라인 자료를 덮지 않도록 한다. 검증 대기 중 즐겨찾기·링크·내보내기를 제한한다.
- 반 입력은 편집을 마칠 때 적용하며, 무효 입력은 현재 선택값으로 돌아간다. 빈 시간표의 사유는 원본 근거 없이 단정하지 않는다.

- 명시한 `OPENCIGAN_TRUSTED_PROXIES`의 직접 피어에서만 전달 IP를 사용한다. 기본은 전달 헤더를 무시한다. 우측부터 신뢰 프록시를 건너뛰어 최초 비신뢰 IP를 선택한다.
- 헤더 길이·홉 수, IP·포트 문법, 중복 Forwarded for, 두 전달 헤더의 충돌을 검사한다. 공유 IP/NAT와 실제 운영 프록시 설정 검증은 별도다.

- Python 전체 `unittest discover -s tests -v`: 101개 통과. 기존 SQLite 통합 테스트도 유지했다. 샌드박스 임시 디렉터리 접근 실패는 정상 권한 재실행으로 구분했다.

## UI·내비게이션·이미지 저장

- 주요 설정·저장·공유·학교·즐겨찾기 버튼의 아이콘을 통일했다. 검색은 2~50자·최대 10건 조건을 안내하고 입력 길이를 제한한다. 정적 404 페이지에 홈 링크를 추가했다.
- 즐겨찾기 접기·빠른 선택·빈 상태, 설정 검색·접기, 포커스/클릭/터치/호버 도움말을 추가했다. 급식 개인 설정은 설정 탭에 유지한다.

- 프런트 단위 83개 통과, Svelte 오류 0·경고 0. 브라우저 15개 통과·기존 WebKit 오프라인 1개 skip. 설정 화면은 320/800/1366px 가로 넘침을 검사했다. 배포 빌드도 성공했다.
- 보안 점검: history 입력의 날짜·학교·학급 범위 및 버전 검증, URL·토큰 비저장, DOM 문자열 이스케이프, 파일명 제어문자·확장자와 캔버스 크기 경계를 확인했다. 실제 모바일 키보드·회전·저장·공유 시트는 별도 확인이 필요하다.

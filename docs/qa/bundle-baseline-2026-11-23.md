빌드 전체 `assets`는 JS 11개 687,110바이트, CSS 4개 198,362바이트, WOFF2 92개 2,957,724바이트다. 전체 파일 크기는 최초 방문 시 모두 다운로드한다는 뜻이 아니다. 폰트 서브셋은 사용 문자와 브라우저 동작에 따라 요청량이 달라진다.

PDF 내보내기 코드는 `pdf-lib`를 동적으로 가져오며, 대형 JS 청크는 생성된 `index.html`의 초기 스크립트·preload 목록에 없다. 메인 스크립트의 이미지 생성 코드는 초기 번들에 포함된다. 이를 분리할 경우 오프라인 셸의 캐시 목록과 모바일 공유의 사용자 활성화 조건을 함께 검증해야 한다.

추가로 동일 빌드의 로컬 Vite 미리보기를 사용해 빈 브라우저 컨텍스트에서 첫 방문을 측정했다. 외부·API 요청과 서비스 워커는 차단했다. Chromium에서 390×844와 1366×844 모두 JS 4개 73,387바이트, CSS 1개 22,807바이트, WOFF2 13개 333,884바이트의 encoded body를 요청했다. 폰트는 표시된 문자에 따라 달라지고, 프로토콜·압축·캐시·OS·브라우저에 따라 실제 전송량은 달라진다. HTML 문서는 이 자원 합계에 포함하지 않는다.

재측정은 `frontend`에서 `npm run build` 후 `npx vite preview --host 127.0.0.1 --port 4174 --strictPort`로 미리보기를 열고, 별도 터미널에서 `node scripts/measure-initial-assets.mjs`를 실행한다. 종료 후 미리보기 서버를 중지한다. 이 스크립트는 루프백만 허용하고 다른 출처와 API 요청을 차단한다.

운영 환경의 실제 전송량·로딩 시간 및 최적화 전후 차이는 측정하지 않았다. ST-13은 후속 최적화와 회귀 검증 전까지 미완료다.

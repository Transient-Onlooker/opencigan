> API·캘린더·관리자·접속 로그를 정리합니다. Cloudflare Tunnel 및 엣지 보안은 P0에서 관리합니다. 체크박스 **[x]는 코드 구현 기록**이지 운영 배포·실기기 QA 완료를 뜻하지 않습니다. [전체 개요](../roadmap.md)로 돌아가기.

## P2 — 외부 개발자 연동

### P2 — ‘만들어주세요’ 기능 요청 접수·관리 (P0 운영 안정화 후, 미구현)

- [ ] **P2 · 익명 기능 제안 접수·검색 API와 저장소**: 회원가입 없이 기능 제목·설명·필요한 상황을 접수하고, 승인된 요청만 공개 검색할 수 있게 한다. 요청 크기·입력 길이·유효성·HTML/스크립트 표시를 제한하며 민감정보 입력을 안내로 억제한다. 새 저장소의 보관 기간·삭제 정책·백업 범위와 기존 사용자 설정/접속 로그 DB 간 데이터 경계를 정의한다. API 미배포 시 프런트엔드의 제출 UI를 활성화하지 않는다.
- [ ] **P2 · 관리자 승인·운영 안전장치**: 접수된 요청은 기본 비공개 검토 대기 상태로 두고, 관리자가 승인·거절·삭제·중복 병합할 수 있도록 인증된 관리 화면/절차를 제공한다. IP 기반 제한·스팸/반복 제출 탐지, 요청 크기 제한, 민감정보 유출·명예훼손 방지, 조회/수정 권한과 CSRF·저장형 XSS를 테스트한다. 관리자 토큰이나 GitHub 쓰기 권한을 브라우저에 노출하지 않고, 공개 여부·보관 기간·삭제 요청 처리 정책을 확인한 뒤에만 운영한다.


### P2 — 설정 클라우드 보관·복원 서버 (보안 설계 선행, 미구현)

- [ ] **저장 API 및 데이터 범위**: OpenCigan 서버에 사용자가 **선택해 저장한** 학교별 표시 설정·과목 색상/별칭·교사 별칭·교시 시각과 필요한 학급별 오버라이드만 버전 있는 스키마로 보관. 기존 JSON 백업 형식과 호환되는 변환/검증, 요청 크기·학교/학급 범위·입력 한도 설정, 저장/조회/삭제 API와 실패 처리 구현. 알레르기·개인 일정·접속 로그 등은 명시적으로 범위에 포함하기 전까지 서버에 전송하지 않음.
- [ ] **익명 식별 및 인증 방식**: 단순 UID/학교 ID/예측 가능한 쿠키 값은 **비밀 인증 수단으로 사용하지 않음**. 서버 발급 고엔트로피 불투명 토큰과 인증용 보호 수단, 수명/회전/폐기, 기기 변경 시 재연결(복구 코드 등)을 설계. 브라우저 쿠키를 쓰는 경우 `HttpOnly; Secure; SameSite`와 CSRF, 실제 GitHub Pages·Cloudflare API 사이의 cross-origin / cookie 정책, CORS·credentials 설정을 검증. 쿠키만으로 여러 기기가 자동 연동되는 것으로 설명하지 않기.
- [ ] **저장 데이터 보호·운영**: 수집 최소화, 명시적 사용자 동의 및 삭제/철회, 보존 기간·백업/복구, 저장 용량 및 IP별 남용 방지, 암호화·접근 통제, 개인정보 처리 안내 검토. 다른 사용자 설정 조회/수정 불가, 토큰 유출·재전송·CSRF·동시 기기 업데이트·복원 충돌에 대한 테스트를 통과한 뒤에만 공개.


**2026-11-16 운영 QA 후속** ([NEW-01/02 원인·공개 게이트](../qa-2026-11-16.md))

**우선순위 이동:** Cloudflare Tunnel 전환·WAF 봇 방어·공개 API/ICS 배포와 Tailscale 비교는 [P0 핵심 품질](core-quality.md#p0--cloudflare-tunnel-공개-api-전환엣지-봇-방어-2026-11-16-우선순위-상향)에서 관리합니다. 이 문서에는 일반 API 기능과 운영 통계 작업만 남깁니다.

- [ ] **NEW-01 (가용성 계측): 프로세스 생존과 외부 의존성 구분**. `/api/v1/status`의 `scope=process liveness` 기존 계약을 보존한다. 관리자 통계에 시간대별 집계, 경로별 오류 분류와 프로세스별 최근 캐시 갱신 시도 관측을 추가했다. 마지막 단일 관측은 제공자 전체의 readiness를 보장하지 않는다. API 요청 처리 중 예상 밖 오류 로그에는 허용된 경로 분류와 예외 종류만 남기고 예외 메시지·검색어를 기록하지 않도록 개선했다. 내장 HTTP 서버의 요청 로그도 메서드·상태만 기록한다. 실제 운영 배포와 별도 readiness 관측은 미완료다.

## P1 — 사용자 편의


**2026-11-16 QA 확인 기반 신규 과제** — 기존 미완료 UX 항목과 중복되는 것은 아래 원래 체크박스를 기준으로 처리. [QA 기록 NEW-01~09](../qa-2026-11-16.md).

- [ ] **NEW-03 (P1): 날짜 필드 입력 중 상태/오류 상태 수정**. 급식에서 `20261225` 연속 타이핑 시 중간 연도 거부로 유효 날짜 확정 실패, 유효 날짜 적용 후에도 오류 문구 잔존. 날짜 편집 draft와 확정 값·검증 시점 분리, 적용 성공 시 경고 초기화. 급식·비교 날짜·개인 일정에서 키보드/붙여넣기/모바일 세그먼트 입력 회귀. 급식·오늘·비교 날짜에서 편집 중 잘못된 중간값을 되돌리지 않고 날짜 붙여넣기를 지원한다. Chromium에서 급식 연속 키 입력·붙여넣기, 학년 비교 날짜 붙여넣기 이벤트와 화면 갱신, 개인 수업 날짜 붙여넣기·일정 저장을 확인했다. 실제 모바일 입력 검증은 남아 있다.
- [x] **NEW-04 (P2): 부정확한 공유 딥링크 안내**. 확인할 수 없는 공유 학급은 임의 보정하지 않고, 기존 선택이 있으면 유지된 학교·학년·반과 적용하지 못한 이유를 안내한다. 기존 선택이 없으면 요청한 학년·반을 표시하고 직접 선택하도록 하며, 확인되지 않은 학급은 저장하지 않는다. 공유 선택 회귀 및 Chromium 화면 검증 완료.
- [x] **NEW-05 (P2): 학급별 설정 파일 버튼의 조건 명시**. 학급별 설정을 켜야 학급 파일 저장 버튼이 나타남을 안내하고, 학교·학급 설정의 적용 범위와 백업 내용을 표시한다. Chromium에서 학교·학급 백업 복원, 학급별 설정을 끈 상태의 안내, 일부 설정이 없는 기존 형식(version 1) 파일 복원을 확인했다.
- [x] **NEW-06 (P2): 독립 페이지 전체 테마·동선 점검**. 위젯의 기존 명시적 테마를 유지하고 위젯 생성기·통계·접속 로그·알림 관리가 메인 사이트의 테마 설정을 따른다. 메인 화면에서 위젯 생성기로 이동할 수 있고 각 독립 페이지에서 원본 사이트로 돌아갈 수 있다. 관리자 도구는 기존 인증 경계를 유지한다. Chromium에서 라이트·다크·시스템 설정과 320·800·1280px 가로 넘침을 확인했다. 실기기 확인은 별도다.
- [x] **NEW-07 (P2): 비활성 변경 이력 카드만 간소화**. 이력 조회에서 저장 비활성을 확인하면 카드를 짧은 상태 문구로 바꾼다. 원본 `isChanged`에 따른 수업 강조와 변동 배지는 유지하며, Chromium에서 비활성 응답과 변동 배지 동시 표시를 확인했다.
- [ ] **P1 · 레이아웃 미세 정렬 및 시각적 일관성 (사용자 제보, 2026-11-17)**: 첨부 화면에서 동일한 행·그리드에 놓인 텍스트, 입력 필드, 버튼, 탭 등의 **가로·세로 정렬과 경계선·여백이 어긋나는 문제**를 찾아 교정. 고정 높이만 임의 적용하지 말고 공통 spacing·line-height·align-items·그리드 기준선을 정립해 섹션 제목·상단 선택 폼·시간표 제어 도구·탭의 시작/끝선과 간격을 맞춘다. 라이트/다크, 선택 전/후, 오류/로딩 상태, 데스크톱 및 320/390/700/960px 모바일·태블릿에서 실측 스크린샷을 비교하고 텍스트 잘림·가로 스크롤·레이아웃 이동이 없는지 확인. **사용자 확인 전에는 완료 처리하지 않음.**
- [ ] **NEW-09 (P3): UI 세부 완성도**. 수동 새로고침 실패 안내를 한 곳에 모으고 과목 직접 색상 선택의 기본값 대비를 높였다. 빈 교시 도움말과 선택 주 기준 집계 설명을 확인했고, GitHub Pages 빌드에는 실제 웹 커밋 SHA를 표시한다. 다른 장애 경로의 중복 안내와 실제 배포 SHA는 별도 확인이 남아 있다. 제거 예정 즐겨찾기 순서 설명에 별도 투자하지 않기.

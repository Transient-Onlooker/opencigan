# 기능 제안 API (격리 구현)

기능 제안 접수는 기본적으로 비활성화되어 있으며 공개 운영을 위한 데이터 보존·삭제 정책은 아직 정해지지 않았다. API 경로·화면의 준비와 실제 운영 서비스 활성화는 별개다.

격리된 테스트 환경에서는 `OPENCIGAN_SUGGESTIONS_ENABLED=1`과 별도 SQLite 파일 경로인 `OPENCIGAN_SUGGESTION_DB`를 지정할 수 있다. 기존 시간표 이력·접속 로그·분석 DB와 같은 파일은 사용할 수 없다. 관리 작업에는 `OPENCIGAN_SUGGESTION_ADMIN_TOKEN`에 충분히 긴 무작위 토큰을 설정하고 `Authorization: Bearer <token>`을 사용한다. 길이 검사만으로 토큰의 무작위성이 보장되지는 않는다.

프런트엔드는 설정 탭에서 제안 API 가용성을 확인하고 정상 응답인 경우에만 ‘만들어주세요’를 보여준다. API가 없거나 꺼져 있으면 제출 폼이 숨겨진다. `VITE_SUGGESTIONS_ENABLED=0`을 설정하면 이 확인을 포함해 프런트엔드 기능을 명시적으로 끌 수 있다. 게이트웨이의 `SUGGESTION_RATE` 바인딩과 Pi 저장 환경이 모두 준비돼야 실제 접수가 가능하다.

- `POST /api/v1/suggestions`: 제목과 설명, 선택적인 이용 상황을 제출하고 본인 조회용 토큰을 받는다.
- `GET /api/v1/suggestions`: 승인된 제안만 검색한다.
- `GET /api/v1/suggestions/{id}`: 제출 시 받은 토큰으로 자신의 제안을 확인한다.
- `GET /api/v1/admin/suggestions`: 관리자용 목록을 조회한다.
- `PATCH /api/v1/admin/suggestions/{id}` 및 `DELETE /api/v1/admin/suggestions/{id}`: 관리자가 상태를 변경하거나 제안을 삭제한다.

제안 저장소는 접속 IP나 브라우저 정보를 저장하지 않는다. 제출 내용에는 사용자가 개인정보를 직접 입력할 수 있으므로 공개 승인 시 내용을 확인해야 한다. 제안 내용은 일반 텍스트로 취급하고 화면 출력 시 HTML로 해석하지 않아야 한다.

SQLite는 WAL 모드를 사용하므로 실행 중인 DB 파일 하나만 복사해 백업하지 않는다. SQLite 백업 API 등 일관된 스냅샷을 사용하고 복원본에서 데이터와 접근 권한을 확인한다.

## 실서비스 활성화 절차 — 운영자가 별도로 수행

1. 제안 내용의 보존·삭제 기간, 승인·삭제 담당자, 백업 정책과 악용 대응 절차를 확정한다. 승인 전 제안은 공개 검색에 나타나지 않는다. 현재 저장소는 최대 2,000건 제한이 있지만 기간에 따른 자동 삭제는 없다.
2. Pi의 별도 영속 경로에 접근 권한이 제한된 SQLite 파일을 준비하고 `OPENCIGAN_SUGGESTION_DB`로 지정한다. 이력·접속 로그·분석 데이터베이스 경로와 분리한다. `OPENCIGAN_SUGGESTION_ADMIN_TOKEN`에는 비공개 고엔트로피 관리자 토큰을 설정한다.
3. 기존 Worker 구성에 `SUGGESTION_RATE` 바인딩을 추가하고 갱신된 게이트웨이 코드를 배포한다. VPC 연결·서명 키 및 기존 Rate Limit 바인딩은 유지한다.
4. 테스트 환경에서 401·429·503·입력 오류와 미승인 비노출을 확인한다. 이어 Pi에서 `OPENCIGAN_SUGGESTIONS_ENABLED=1`을 설정하고 서비스를 재시작한 다음, 공식 도메인에서 익명 제출(201), 공개 검색, 관리자 승인 후 공개, 중복(409), 제한(429)을 확인한다.
5. 이상이 있으면 Pi의 기능 플래그를 끄고 서비스를 재시작한다. 프런트엔드는 API 가용성 확인 실패 시 폼을 숨긴다. DB는 임의로 지우지 않고 정해진 보존 정책대로 관리한다.

**남은 UX 제한:** 별도 웹 관리자 화면은 없으며 승인·거절·삭제는 인증된 API로 처리한다. 작성자가 받은 일회성 조회 토큰을 브라우저에 보관·제시하는 UI는 아직 없으므로, 작성자 본인 조회는 API로만 가능하다. 토큰을 소스/로그/브라우저 공개 환경변수에 넣지 않는다.
